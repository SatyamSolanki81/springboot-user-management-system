# Spring Boot User Management System

## Overview

This project is a User Management REST API developed using Spring Boot. It provides CRUD operations for managing users and demonstrates backend development concepts.

## Features

* Create User
* Get User By Username
* Get All Users
* Update User
* Delete User

## Tech Stack

* Java 21
* Spring Boot
* Spring Data JPA
* MySQL
* Maven

## Project Structure

* Controller Layer
* Service Layer
* Repository Layer
* Database Layer

## API Endpoints

### Create User

POST /user/createUser

### Get All Users

GET /user/getAll

### Get User By Username

GET /user/getUser/{username}

### Update User

PUT /user/updateUser/{username}

### Delete User

DELETE /user/deleteUser/{username}

## Future Enhancements

* Input Validation
* Global Exception Handling
* JWT Authentication
* Role Based Authorization
* Docker Support
